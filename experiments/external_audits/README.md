# External missingness audits

Descriptive audits of the cloud and gap structure behind three published
crop-type transfer papers (TimeMatch, DENETHOR, DACCN), measured from each
paper's own data or deposited recipe. No model is re-run. See
`docs/superpowers/specs/2026-10-28-external-missingness-audits-design.md`.

Layout, how to run, data root and clean-up behaviour are documented at the end
of the implementation (Task 14 of the plan); until then each paper folder's
scripts are run in numbered order from the `ee` conda environment.
